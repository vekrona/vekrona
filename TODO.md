Seen 2026-10-03 as four SIGSEGVs from `vekrona-screenshot area`, run four times while Sway lagged under an install run, which delays frame callbacks until after slurp exits. Fixed upstream in emersion/slurp "Fix wl_callback use-after-free in send_frame()" (2025-10-18), not in any release yet (latest tag v1.5.0).
