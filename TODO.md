The Desktop Entry spec (Exec, "The Exec key") says: "Note that the general escape rule for values of type string states that the backslash character can be escaped as `\\` as well and that this escape rule is applied before the quoting rule. Likewise, a literal dollar sign in a quoted argument in a desktop entry file is unambiguously represented with `\\$`." The line is `WARN`, so it never reaches the error store; it is only noise in the journal.
