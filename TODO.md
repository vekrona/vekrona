- `ensure_root_file` in `lib/common.sh` compares content only, so a file with the wrong mode (for example a sleep hook that lost its executable bit) is reported "up to date" and never repaired. Compare `stat -c %a` with the wanted mode too and reinstall on a difference.
- `ensure_pkg_from_repo` (`dnf repoquery ... 2>/dev/null || true`), `pkg_installed` (`rpm -q` with all output dropped), `repo_enabled` (`dnf repolist 2>/dev/null`) and the `systemctl is-enabled ... || true` probe in `ensure_system_unit` swallow command errors: a broken rpm database or dnf failure reads as "not installed" or "not enabled". Mostly the following install or enable step then fails loudly, but `repo_enabled` and `ensure_pkg_from_repo` can silently take the wrong branch.
